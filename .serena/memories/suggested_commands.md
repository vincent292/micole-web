# Commands
- npm run dev: Vite server.
- npm run build: TypeScript + Vite + SEO generation.
- npm run test: configured suite; npx vitest run tests/<relevant>.test.ts: focused tests.
- npm run test:e2e: Playwright.
- serena project index .: warm index; serena memories check: memory links.
- Inspect --apply scripts: they can mutate remote state.
