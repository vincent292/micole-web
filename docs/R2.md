## Cómo continuar

Desde el proyecto web, `npm run supabase:verify:r2` comprueba la conexión privada con un objeto sintético; `npm run supabase:setup:r2` verifica, guarda secretos y despliega `r2-media`. Estos comandos usan `.env.r2.local` y una sesión válida de la CLI de Supabase.

Leer este documento antes de recrear buckets o tokens. Conservar los cambios locales existentes en ambos repositorios. La creación y configuración de almacenamiento no autoriza generar APK ni publicar nuevas versiones.
