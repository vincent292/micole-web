# MiCole · Identidad aplicada

Paleta definida por el producto:

| Uso                                             | Color     |
| ----------------------------------------------- | --------- |
| Principal: botones, enlaces y navegación activa | `#3D6EF7` |
| Secundario: identidad y acentos positivos       | `#54D2A0` |
| Acento: indicadores y detalles                  | `#FFC857` |
| Texto principal y títulos                       | `#263238` |
| Fondo                                           | `#F8FAFF` |
| Superficies y tarjetas                          | `#FFFFFF` |

Poppins 600/700/800 para títulos y marca. Inter 400/500/600/700 para la interfaz. Las fuentes se sirven desde la aplicación mediante Fontsource; no requieren una petición a Google Fonts.

Los logos originales permanecen en `public/illustraciones`. Sus copias con nombres estables están en `public/brand`. El componente `Brand` muestra las versiones horizontal, símbolo, blanca y con lema, usando el mismo PNG original dentro de un SVG para ajustar los márgenes transparentes sin modificar el logo.

Los estados positivos combinan fondos claros de verde con texto verde oscuro, para evitar texto verde claro sobre blanco. El amarillo identifica detalles y avisos; los textos se mantienen oscuros.

La landing utiliza fondos claros y tarjetas blancas, azul como acción principal, y verde/amarillo en los detalles. Cada colegio puede conservar su logo y color institucional dentro de su espacio.
